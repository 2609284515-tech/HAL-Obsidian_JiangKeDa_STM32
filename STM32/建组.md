# HAL库

在工程文件夹下建xx文件夹
在CMakeLists.txt的target_include_directories下一行写
```
${CMAKE_CURRENT_SOURCE_DIR}/xx
```
所有建的.c文件都在CMakeLists.txt的target_sources下一行写
```
${CMAKE_CURRENT_SOURCE_DIR}/xx/xx.c
```
如果不想用这个c就把这行删了，这样不用配置它的GPIO

记住复制，改名，移动工程时把Build文件夹删了
